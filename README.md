I've always wanted a button that turns my PDF lecture timetable into a portable .ics calendar file. Now I have it, and you can too!

```text
go run . -input timetableFile.pdf -output outputName.ics
```

Imported lecture times represent local Vilnius time.

If the calendar output file is incorrect, please [create an issue here ](https://github.com/megazvezda/happiness/issues/new/choose) and include the input .pdf file, or email me at shtol[at]duck[dot]com
